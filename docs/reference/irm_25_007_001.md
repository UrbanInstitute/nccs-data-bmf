# IRM 25.7.1 — Exempt Organizations/Business Master File and Support Processing

**Source:** https://www.irs.gov/irm/part25/irm_25-007-001
**Effective Date:** January 1, 2026

This is the authoritative IRS reference for EO/BMF field definitions, code values, and validation rules. It governs how the BMF extract data processed by this pipeline is structured and what each field means.

---

## File Structure

The EO/BMF consists of records with two components per entity:
1. **Entity Module:** Identifying and exemption data
2. **Return Section:** Data from EO returns and examinations

---

## Core Data Fields

### BMF Entity Module (Common Fields)
- **EIN:** 9-digit Employer Identification Number (assigned by Entity Control, unchangeable except via TC 011)
- **Name Control (NC):** 4-character code derived from first significant characters of organization name
- **Check Digit (CD):** Generated from EIN, cannot be changed
- **Establishment Date:** Date organization posted to BMF, unchangeable
- **Employment Code (EC):** Identifies employment tax requirements
- **Fiscal Year/Month (FY/M):** Organization's accounting period
- **Filing Requirement Code (FRC):** Indicates required return forms
- **Primary Location Code (PLC):** Area Office code based on mailing address

### Print Name Lines (4 lines, generated from EO Section)
1. Organization Name
2. Sort Name
3. Foreign/Location Address
4. Care of Name (c/o)

### Address Fields
- Street Address (max 35 characters)
- City (max 20 characters)
- State (2-character code)
- Zip Code (5 or 9 digits, range 00601–99999 or 006010000–999999999)

---

## EO Section/Submodule Fields

### Subsection (SS) Code
Identifies IRC section under which organization is exempt. Valid codes: 01–27, 40, 50, 60, 70, 71, 80, 81, 90–93, 99 (for deletion).

### Classification Code (CL)
Organization type/purpose. Valid values: 1–8 (up to four codes per entity).

### Status Code (ST)
Current and prior exemption status. Valid codes:
- **01:** Active exemption granted
- **06–07, 10–11, 12, 18–20, 22–26, 28:** Various denial/revocation statuses
- **40–42:** Special statuses
- **70–72:** Termination statuses

### Status Date
Date status code became effective (CCYYMM format).

### Foundation Code (TF)
Required for IRC 501(c)(3) organizations only. Valid codes:
- **02:** Private Foundation (subject to Net Investment Income Tax)
- **03, 04:** Public Charity classifications
- **09–18:** Public Charity by organizational type
- **99:** Deletion marker

### Affiliation Code (AF)
Indicates individual or group ruling:
- **1, 2, 3:** Individual determination/ruling
- **6, 7, 8, 9:** Group ruling designations

### Ruling Date (RD)
Date exemption was granted (CCYYMM format).

### Group Exemption Number (GEN)
4-digit identifier for subordinate organizations under group ruling (range 0001–9998).

### Deductibility Code (DC/DY)
Indicates contribution deductibility status:
- **1:** Deductible contributions
- **2:** Non-deductible contributions
- **4:** Deductible under treaty provisions
- Format: 1 digit code + 4-digit year (DCCYY)

### Type of Organization (TO)
- **1:** Corporation
- **2:** Trust
- **3:** Cooperative
- **4:** Partnership
- **5:** Association
- **6:** NECT (Non-Exempt Charitable Trust, SS must be 91 or 92)

### Area Office (AO) Code
2-digit district identifier (valid: 11, 31, 52, 75, 95 for AOs; 50 for HQ).

### Advance Ruling Date (AD)
Expiration date for advance ruling status (CCYYMM), or 999999 to delete. Used only when organization status is 25.

### Large Case Code (LC)
- **1:** Current large case designation
- **2:** Former large case
- **9:** Deletion marker

### Cumulative List Indicator (CU)
Determines Publication 78 listing eligibility.

### Pension Plan (PP) Code
- **1:** Organization has pension plan
- **2:** No pension plan or unknown
- **9:** Deletion marker

---

## Organization Name Fields

- **Organization/Primary Name:** Legal organization name (max 140 characters across 4 lines)
- **Sort Name (SN):** Alternate business name or trade name (max 35 characters). Input "$$" to delete.
- **In Care of Name (CO):** Correspondence recipient name (max 35 characters). Format: % prefix + space + name. Input "$$" to delete.
- **Foreign or Location Address (FA):** Complete address for foreign-located organizations (max 35 characters). Input "$$" to delete.

---

## Return Data Elements

Transcribed from EO returns and retained on BMF:
- **Total Assets (End of Year)**
- **Total Income or Gross Receipts**
- **Asset Code:** Derived from assets
- **Income Code:** Derived from income

---

## Filing Requirement Codes (FRC)

### EO-Specific Returns
- **990:** Organization Exempt from Income Tax (codes: 01, 02, 03, 04, 06, 07, 13, 14)
- **990-T:** Unrelated Business Taxable Income (codes: 0, 1)
- **990-PF:** Private Foundation Tax Return (codes: 0, 1, 3)
- **5227:** Split-Interest Trust Information (codes: 0, 1, 2)

### Employment/Payroll Returns
- **941:** Employer's Quarterly Federal Tax Return (codes: 00, 01, 07)
- **940:** Employer's Annual Federal Unemployment Tax (codes: 0, 1, 7)
- **943:** Agricultural Employer's Quarterly Tax (codes: 0, 1, 7)
- **720:** Quarterly Federal Excise Tax (codes: 0, 1, 4, 6, 7)
- **1042:** U.S. Withholding Tax (cannot exceed 0)

### Income Tax Returns
- **1120:** Corporation Income Tax (codes: 00, 01, 03, 04, 07, 09)
- **1065:** Partnership Return (codes: 0, 1)
- **1041:** Fiduciary Income Tax (codes: 0, 1)

### Special Returns
- **2290:** Heavy Highway Vehicle Use Tax (codes: 0, 1, 2)
- **11C, 730:** Excise tax filings (paired requirements; must match)
- **NR (Not Required):** Code 1 indicates filing not required

## Business Rules & Validation Logic

### Name Control Rules
Exclude the word "The" when used as prefix and followed by multiple words. For trusts, derive Name Control from surname.

| Name | Code |
|------|------|
| Minnow Bass of Free Zinnia | MINN |
| Fig Daisy Helpers Union | FIGD |
| (The) Beagle of Little Apple | BEAG |
| The Grayling | THEG |

### Subsection-Foundation Code Constraints

- When SS = 03 or 71: TF must be 02, 03, 04, or 09–18 (unless status 70–72, then TF prohibited)
- When SS = 03 and TF = 02: FRC must include 990-PF = 1 (not standard 990)
- When SS = 90 and TF not required: FRC must be 5227 = 1 or 2
- When SS = 91 and TF not required: FRC must be 990 = 1 or 2
- When SS = 92 and TF not required: FRC must be 990-PF = 1

### Status Code Validation

**TC 000 + Document Code 80:**
- ST=01 requires SS in {01–25, 40, 50, 60, 70, 80}
- ST=07 requires SS blank, FRC 990-T=1, FRC 990=6
- ST=10 requires SS blank, FRC 990=6
- ST=11 requires SS blank, FRC 990=6
- ST=12 requires SS in {90–93}

| 4 (Partnership) | 40 |

| 6 (NECT) | 91, 92 |

### Address Validation
- Street Address: Max 35 characters; alpha, numeric, hyphen, slash, ampersand, blank allowed
- City: Max 20 characters; alpha, numeric, hyphen, blank allowed; consecutive blanks or leading blank invalid
- State: Valid 2-character state code required if city entered
- Zip: 5 or 9 digits; range 00601–99999 or 006010000–999999999; digits 5–6 cannot both be zero
- Foreign Address: City field = country; State field = period; Zip = blank

### GEN (Group Exemption Number) Rules
- Valid range: 0001–9998 for existing groups
- When AF=6, 7, 8, 9 (group ruling): GEN required
- When changing from individual to group or vice versa: AF code must change and GEN updated

### Fiscal Year/Month (FY) Requirements
Must be entered with positive FRC for forms 990, 990-PF, 990-T, 5227, 1041, 1065, 1120.

## Key Processing Notes

### EO Entity Record Components
The EO Entity Record contains unique information identifying the organization as having been granted tax exempt status, including:
- Name and address
- Filing requirements
- Filing history
- Organization type
- Current/prior IRC subsections
- Exemption grant, denial, revocation, or termination dates since January 1981

### Data Retention
Prior SS Code and ST data are maintained at the Master File and available for reference on IDRS. When EOMF merged with BMF (January 1981), generally only active EOMF accounts were placed on the BMF.

### Exceptions
- Individual churches/synagogues affiliated with denominations: typically excluded from individual BMF records
- Federally-chartered organizations (Federal Credit Unions, Federal Land Banks, etc.): exempt under IRC 501(c)(1), typically excluded from EO/BMF
- State-chartered credit unions under group exemptions: may be omitted at Area Office Manager discretion

### Important Cautions
- "Be sure that the TF 02 is correct before inputting it, as it exempts the organization from paying the IRC 4940 Net Investment Income Tax."
- "Any EOCHG input will create an EO Section on the BMF; therefore, be sure it is an EO account before using CC EOCHG."
